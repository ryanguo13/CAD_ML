# 阶段 B 执行记录：冻结表征与单分支对照

本记录承接 [第一轮执行记录](执行记录_2026-10-10.md)，对应 [模型规划](模型调研与架构方案.md) 的阶段 B。E0 的数据锁和原结果保留，新增 E1 ECG-FM、E2 ECG-CPC/S4（官方 query-attention 和 mean-pooling 对照）、E3 保幅 local-only。E4 融合尚未训练。

## 固定协议

沿用 `artifacts/data_v1` 的 17,905 条合格公开记录，训练/选择/校准/评估为 10,723/1,798/1,795/3,589，评估集含 3,394 位患者、228 条 OMI 阳性 ECG，阳性率 6.35%。1,993 条有效隐藏标签记录不参与缓存、拟合、校准或评估。

三个预定种子为 17、43、101，各训练 8 轮，以选择集 OMI average precision 选 checkpoint。独立校准集拟合 Platt 截距和斜率；95% 灵敏度阈值仅由选择集确定。评估用患者聚类 bootstrap 1,000 次。各方法沿用 AdamW、学习率 0.001、weight decay 0.0001、有效 batch 32、无类别重加权和无增强。E3 使用 batch 8、梯度累积 4，其余使用 batch 32。

所有模型只训练 OMI 单任务，不输入诊断、造影、PCI 或检查间隔。波形读取先解码 ADC gain/baseline 到 mV，再检查 12 导联、500 Hz、10 秒和有限非平坦信号。数据 manifest SHA256 为 `f05d2e24295d9bfc757e5fc8c9e980ac7c3360bf254a918cf4216d8b511df3ca`。

## 权重和预处理

### E1 ECG-FM

- 作者 ECG-FM 代码 commit：`9f926f1911bb9f24789b5c6407677d58ad753054`；fairseq-signals commit：`f8f0ff1c788a82c2059cb452cd5462898867489e`。
- HuggingFace revision：`584219ea492cdeef2e19ffbdf9c6ecc874ba427e`；基础权重 SHA256：`4d0142bcb485eb9f0c7845e0c19ff3463f6ae9d0e458eab69136efe90ceb9b7e`。
- 官方加载器严格加载，实际为 12 层、768 维、90,883,072 参数；下载的附带 YAML 写 24 层/1024 维，与 checkpoint 不一致，以 checkpoint 内部配置为准。
- 采用作者 quickstart 和 `ecg-transform==0.1.3`：完整 10 秒逐导联 Standardize，再切前后两个 5 秒窗口；没有额外滤波。各窗口取最终 Transformer `x`，按官方 nonzero mean pooling 得到 768 维，保持前后顺序拼接为 1,536 维。
- 仅训练患者拟合 embedding 的固定均值和标准差。预测头为 1536→128、GELU、dropout 0.2、OMI 线性头，共 196,865 个可训练参数。骨干冻结且始终 eval。
- 缓存为 float16，17,905×1,536，约 55 MB。锁定 checkpoint、配置、原始波形/header、索引、官方源码和适配代码哈希及依赖版本。
- 权重/代码许可记录为 MIT。预训练包含 MIMIC-IV-ECG 和含 PTB-XL 的 PhysioNet Challenge 2021；这些数据不能作为该权重的严格未见外部评估。造影队列没有被报告为预训练来源，但无法核实个人重叠。

### E2 ECG-CPC/S4

- 官方基准代码 commit：`238409835ef55358a10bbc3459dfa9aaa91ad5e5`。Figshare article 30192604、file 58173919；ZIP MD5 为 `7cdd0d54786b4d98248afc6dce63beea`，与发布元数据一致。
- `last_11597276.ckpt` SHA256：`bc253edc6ac279ce2caec86d3c3a21b740e43735ca03be1dc7c50e630b0ad4cf`。最初几个入口返回 403，带 query 的官方 API 入口最终成功；这项下载阻塞已解除。
- 官方预训练 YAML 为 240 Hz、10 秒、不归一化，卷积 kernel 3/1/1/1、stride 2/1/1/1、512 通道，4 层 causal S4，state dimension 8。附带下游 YAML 用 2.5 秒；序列化 hparams 又包含 100 Hz、kernel 全 1 等默认值。实际第一层权重为 `[512,12,3]`，FFT 缓冲为 601 个频点（1200 步）。本实验依据官方原生配置和权重形状处理完整 10 秒，严格加载 encoder/predictor。
- 采用官方所用的 `resampy==0.4.3` 默认 kaiser_best 从 500 重采样到 240 Hz，保持 mV，不做逐记录标准化。缓存官方最终 S4 序列 `[1200,512]` 的 float16 token；另缓存同一 token 的 float32 时间均值。
- 这里采用官方下游 `Resample` 的处理流程。HEEDB 数据准备脚本还默认将预训练波形裁剪至 ±3 mV；本次造影输入沿用下游不加裁剪的流程，不将这项迁移适配称为 HEEDB 预处理的完整复现。
- Windows 未提供官方 Cauchy CUDA 扩展。本实验只将共轭 Cauchy 求和换成等价的 PyTorch 复数表达式，encoder、S4、残差、归一化及权重保持作者实现。独立代数检查最大误差 `9.99e-16`；四层 checkpoint 的 1200 步 FFT 与 dense 状态递推最大绝对误差 `4.36e-7–7.09e-7`，相对 L2 误差 `5.09e-7–6.72e-7`。后端差异在配置和结果中明确记录。
- 冻结 encoder/predictor 有 2,932,736 个参数（不含预训练 SSL 头）。主要读出直接使用作者 `LearnableQueryAttentionPoolingHead`，16 heads、bias=false，共 787,456 个可训练参数；mean-pooling 加 512→1 线性头有 513 个参数。没有从已池化向量重建 token。
- 权重许可由 Figshare 元数据核实为 CC BY 4.0；固定源码 ZIP 没有仓库 LICENSE 文件，后续分发需核查各上游组件的许可。作者报告预训练来自 HEEDB；PTB-XL 是下载包中下游示例配置的来源，不能据此推断这份基础 checkpoint 已在 PTB-XL 微调。各数据个人重叠无法核实。

### E3 本地保幅分支

实现设计规格中的共享逐导联多尺度卷积、导联身份、一层跨导联注意力、膨胀时序卷积、有序 mean/max 池化及 48 维幅值统计旁路，共 425,345 个参数。原始波形保持 mV，不作逐记录 z-score；统计旁路仅由训练患者拟合固定尺度。该分支在本轮从零训练，尚未做 PTB-XL 表型预训练。

## 已完成的验证

原有 ResNet/local/fusion 的形状、反向传播和参数预算检查通过；标准化顺序、训练尺度隔离、缓存 provenance 修改拒绝和 compileall 通过。CPC 严格加载、确定性重复输出、保幅重采样、Cauchy/状态递推及官方 query 头反向检查通过。ECG-FM 原始推理与 float16 缓存的向量相对误差约 0.026–0.030%，三个种子的校准概率最大绝对差为 `1.30e-5`，位于预设检查容差内。

## 结果与阶段状态

**阶段 B 已全部完成。** E1、E2 query、E2 mean-pooling 对照和 E3 均完成三个预定种子、每种子 8 轮、独立校准及患者聚类内部评估。完整结果见 [汇总表及配对区间](../artifacts/stage_b_summary/results.md)、[机器可读汇总](../artifacts/stage_b_summary/results.json) 和 [ROC/PR/校准曲线](../artifacts/stage_b_summary/omi_e0_e1_e3_e2.png)。

E3 的 AUROC 为 0.8670–0.8831，AUPRC 为 0.3701–0.3916，Brier 为 0.04722–0.04815，实际灵敏度为 89.5–92.5%，漏诊 17–24 条阳性 ECG。E3−E0 三种子平均差值的患者配对 95% CI：AUROC `[0.00851,0.03605]`、AUPRC `[0.01567,0.08481]`、Brier `[-0.00356,-0.00097]`。E1−E3 的三个区间均跨零，当前不能据此断言两者谁更好，也不能证明融合必有收益。

本机 ECG-FM 向量提取用时 191.8 秒，峰值 CUDA allocated 约 448 MiB；CPC token 提取用时 1,179.6 秒，峰值约 255 MiB，token 文件 22.00 GB（另加均值和索引）。冻结 CPC 参数更少，但完整序列缓存和 query 读出增加了存储/训练成本；不能只按骨干参数数目推断整个流程更快。本轮部分工作并行，时间记录不是严格的独占硬件吞吐基准。

CPC query−E0 的平均 AUPRC 差值 95% CI 为 `[0.03596,0.11972]`，Brier 为 `[-0.00569,-0.00179]`，AUROC 差值区间跨零。CPC query 与 ECG-FM、local 的三个指标配对区间都跨零，本轮不能按一个均值认定谁全面领先。CPC query−mean 对照的 AUROC 差值区间为 `[0.11591,0.16940]`，AUPRC 为 `[0.21419,0.34753]`，Brier 为 `[-0.01453,-0.00765]`。这支持当前预算下使用合理 token 读出；mean 对照三个种子都选择第 8 轮且选择集 AP 仍在上升，不能把此结果推广成充分收敛后所有均值读出都差。

三种主要候选 E1、E2 query、E3 均未达到评估集 95% 灵敏度点估计。mean 对照达到 96.5% 点估计，但特异度约 25.8%，每个种子误报 2,493–2,494 条，且患者区间不能证明临床验收。未根据评估结果重新调整阈值，也未为了改善结果加训或替换协议。

目前 E1 相对 E0 的三种子平均 AUROC 差值患者配对 95% CI 为 `[0.0061,0.0412]`，AUPRC 为 `[0.0234,0.1212]`，Brier 为 `[-0.00460,-0.00111]`。个别种子的差值区间跨零，不能宣称每个种子都显著。

所有结果都是曾经探索过的同源造影队列内部评估，不是外部或临床验证；高 NPV 不能作为临床排除 OMI 的依据。没有完整 CAD 金标准，因此 CAD 总概率仍不可估计。亚组结果仅描述，不作小亚组推断；QC 排除敏感性分析及真实外部评估尚待后续数据与协议。

CPC query 和 mean 两种读出的原始推理/缓存检查通过，训练样本上 token 相对 L2 差异约 0.100–0.128%，六次校准概率比较在本次 AMP 精度下均相同；ECG-FM、本地分支和 CPC 的原始 ECG 推理入口均运行成功。全部训练进程已正常退出。

下一阶段为 E4：在保留以上对照与患者划分的基础上，训练 ECG-FM+local 融合，并以预先声明的指标验证是否互补，再考虑 AMI 多任务及 PTB-XL 表型预训练。阶段 B 的结果不能预先保证融合有效；本轮没有启动 E4。
