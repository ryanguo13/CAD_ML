# 架构独立审查：适合本项目的可消融组合

日期：2026-10-09。本文是针对 `ECG_CAD项目规划.md` 和本地审计统计的架构设计建议，不是已训练模型或性能结论。全文不把新模块的理论合理性写成已证实的 OMI 增益。

## 1. 推荐结论

在本项目中，“拼接”应该按信息职责进行：**局部 CNN 读 P/QRS/ST/T 形态，跨导联模块读空间分布与镜像改变，短序列时序模块读整段节律及跨心搏一致性，独立任务头和校准器负责终点区分与概率。** 不需要同时放入 GNN、Mamba、Transformer、BiLSTM 和多尺度频谱分支。

建议保留两条明确的比较线：

- **迁移线**：使用经核验、可取得权重且许可合适的 ECG 预训练模型，保持其原生骨干和预处理，先冻结编码器训练 OMI/AMI 头，再按资源决定解冻。此线由最新模型检索结果选择骨干。
- **本项目组合线**：约 1–2 M 参数量级的逐导联局部 CNN → 一层跨导联注意力 → 两层时间 Transformer → 多任务头。先证明胜过同量级 CNN-only，再比较与迁移线的效益。它可以用本项目相同结构在 PTB-XL/MIMIC 预训练，不能自动继承其他骨干的预训练权重。

这是研究型推荐。正式主模型由预先规定的开发集指标和消融选定；不要因为组合线“模块多、名字新”而跳过迁移基线。已核验硬件 RTX 5060 8 GB 支持先做紧凑模型与冻结特征实验，尚未实际测量下述模型显存和吞吐。

## 2. 数据对架构的硬约束

- 核心标注仅 17,960 条 ECG、17,018 人；OMI 1,151 条、AMI 2,679 条。患者级训练划分后有效阳性更少，不能按 100 GB 未标注波形规模设计有监督网络容量。
- 核心数据是 500 Hz、10 秒、12 导联；同一记录的原始波形和中位波形不能跨划分。
- PTB-XL 的 MI 是心电诊断代码集合，核心集 AMI 是历史临床诊断，GU 的 AMI 字样又可指急性缺血，必须保留独立标签语义。
- 不能把 MIMIC/PTB-XL 记录默认设成 OMI=0 或 CAD=0。跨数据训练必须使用未知标签 mask。
- 核心数据中的 OMI 和 CTO 目前未共现，**这不构成两者在临床上互斥的证据**，不要因此写互斥 softmax。
- 正常 ECG、低 OMI 风险和无 CAD 不是同一事件。当前架构不输出 CAD 总概率。

## 3. 可直接进入工程设计的组合线

建议暂用内部描述名 **Lead–Time ECG Encoder**；它是项目设计，不冒称某篇现成模型、某种标准或现成 SOTA。

### 3.1 输入和输出

主输入 `X ∈ R[B,12,5000]`，单位 mV，固定导联顺序 I、II、III、aVR、aVL、aVF、V1…V6。

同时维护 `lead_mask ∈ {0,1}[B,12]`；若有逐点无效编码，另有 `sample_mask`。固定尺度转换可以使用 `X / 1mV`，但不逐条、逐导联做 z-score 或 min-max。这样不会在输入处抹掉 ST 与 QRS 的绝对幅值及导联间相对幅值。

临床主头：OMI、AMI，各 1 个 logit。ECG 表型头：先按 PTB-XL 官方聚合建立 STTC、MI、CD、HYP，再选择样本充分的 AFIB、CLBBB、CRBBB、1AVB 等；总类别数 K 由标签字典冻结。ACS/CTO 属于后续独立消融，不是首版每个头都加。

### 3.2 张量流程

| 环节 | 建议参数 | 输出形状 | 目的 |
|---|---|---|---|
| 物理量解码、QC | 保留 mV、导联顺序和缺失 mask | `[B,12,5000]` | 保护单位及输入语义 |
| 合并导联到 batch | 共享逐导联编码器 | `[B×12,1,5000]` | 控制容量，所有导联共享形态词汇 |
| 多尺度卷积 stem | 3 个 Conv1d 分支，核 15/31/63，各 16 通道，stride=2，same padding，concat | `[B×12,48,2500]` | 覆盖约 30/62/126 ms 的初始局部窗口；不是说已识别 P/QRS/ST |
| 残差块 1 | 两层 kernel=9；第一层 stride=2；48→64 | `[B×12,64,1250]` | 学习局部组合 |
| 残差块 2 | 同上；64→96 | `[B×12,96,625]` | 扩大感受野 |
| 残差块 3 | 同上；96→96 | `[B×12,96,313]` | 累计下采样16；最大理论感受野约 399 原始点，即约 0.80 秒 |
| 恢复导联轴 | 转置与 reshape | `[B,313,12,96]` | 同一时刻比较导联 |
| 一层导联注意力 | d=96，4 heads，FFN=192，加入导联身份 embedding；缺失导联不能作 key/value | `[B,313,12,96]` | 学习相邻及镜像导联关系；不强加固定冠脉血管图 |
| 有序导联合并 | mask 后按固定顺序 flatten 12×96，再 Linear(1152,192)；另外加 Linear(mask12,192) | `[B,313,192]` | 保留导联身份，压缩时序长度前的空间信息 |
| 两层时间 Transformer | d=192，4 heads，FFN=384，时间位置编码，双向自注意力 | `[B,313,192]` | 整个10秒内心搏与节律上下文 |
| 全局读取 | 沿时间 masked mean 与 masked max concat | `[B,384]` | 简单、易消融，保留局部强响应和总体模式 |
| 任务头 | 每任务小 MLP：384→128→logit；必要时共享第一个投影 | OMI `[B,1]`，AMI `[B,1]`，表型 `[B,K]` | 区分标签来源与任务语义 |
| 冻结后校准 | 每个临床头独立 logistic/Platt 校准 | `[B,1]` 概率 | 在指定队列中改善概率刻度 |

残差块的 shortcut 在 stride 改变时也投影/下采样。上述形状按 padding 保持 ceil(L/stride) 计算；参数约 1–2 M 仅为设计估算，工程实现后报告确切参数量、FLOPs 和峰值显存。

**为何先融合导联再做时间注意力：** 全局把 12×313 个 token 一次性送入 Transformer，会使 attention 的二次项大幅增大。分解为每时刻 12 个导联 token，再对 313 个时间 token 建模，更适合 8 GB；同时保留同步 12 导联的生理比较。这里没有证明这种分解优于所有全局注意力，是一个要检验的容量取舍。

**为何不立即加解剖 GNN：** ECG 导联不是冠脉血管节点，血供变异、镜像变化、导联冗余和 LBBB/起搏都会削弱简单固定图。先让导联身份和注意力学习关系；如果加入临床先验图，必须与同参数量注意力比较。

### 3.3 规范化与幅值

输入不做每记录标准化。CNN 可用常规 BatchNorm，但统计只从训练数据取得，推理冻结；混合数据源训练后需验证域间偏移，小 batch 不稳定时比较其他方案。不要声称“加了 LayerNorm 就完全保留了绝对幅值”：特征归一化也会影响幅值可辨识性。

重要的是保留未经逐条缩放的输入通道，并实际做幅值敏感性检查。若神经网络仍偏好忽略幅值，可增加一个极小的、经过质量控制的物理测量旁路，例如每导联 ST/QRS/T 测量值加测量失败 mask；**前提是定位与测量算法已核验**。当前只有统计特征基线，不能把简单分位数命名为 ST 测量。该旁路不列为默认必备模块。

普通训练噪声可用小幅噪声、有限时间平移；禁用时间反转、任意导联置换、任意极性翻转和大幅电压缩放。高通、重采样及卷积下采样都可能影响 ST 或起搏脉冲，需分别检查。结构上采用多尺度并不免除波形处理验证。

## 4. 质量、缺导联与可解释性

- 主任务先以合格标准 12 导联为适用范围。缺导联训练是鲁棒性实验，不是自动取得“任意导联都可用”的资格。
- 缺导联以 mask 表示；填零只可作为张量占位，不把零当真实等电位线，也不能把不可读记录输出为低风险。
- 只对明确无效/缺失的信号使用硬 mask。连续质量分数若直接乘到波形上，会降低真实 ST 幅值；不这样做。学习得到的质量门控也可能压低有病但复杂的波形，必须审计被抑制病例。
- 不直接新增“质量疾病分类头”。先使用可重复的削顶、平线、无效编码和噪声指标，质量差返回复查/不可评估状态。机器质量分数未经验证不叫“模型可信度”。
- 导联注意力图、Grad-CAM、积分梯度仅作为模型敏感区域；不能当作罪犯血管、缺血病因或医生解释的真值。展示应与可验证波形和特征对齐，并检查插入/删除、导联遮挡、重复稳定性等。
- 六个肢体导联存在代数关系。自监督时只遮掉一个衍生肢体导联可能很容易重建，未必学到缺血。若做 lead-mask 重建，考虑分组遮挡/时间块遮挡，并报告对简单代数恢复的优势。

## 5. 训练流程与多任务损失

### 5.1 阶段顺序

1. 同一患者划分下训练普通 12 通道 CNN-only OMI 基线；保留参数量、训练预算尽量匹配的比较。
2. 训练上述组合线，只用 OMI。先回答局部+空间+时序是否优于 CNN。
3. 在同结构上加入 AMI；检查 OMI 是否被负迁移。先不同时加入一批稀有标签。
4. PTB-XL 对同结构做表型预训练，再迁移核心临床任务。若最后仍输出表型，需要小比例 PTB-XL 训练回放或冻结独立表型编码器，防止遗忘；最终分别在各自合法验证集上评估并校准。
5. 与公开权重的冻结/轻微微调 ECG foundation encoder 比较。这条线原生结构保持完整，不假装把异构权重装到自定义 CNN 中。
6. 只有迁移收益或标签效率值得时，才考虑本地 MIMIC 自监督。先用开发患者子集验证目标与增强，再增加规模；预训练测试排除规则需先写清。

### 5.2 损失及采样

每个任务对已知标签计算 BCE，按已知样本数归一化；全未知任务跳过。不同头的 loss 需各自归一化，不能因为 PTB-XL 有 K 个表型就让它在总损失中自然放大 K 倍。

起点可用 `L = L_OMI + 0.5 L_AMI + 0.2 L_phenotype`；这三个系数是**待验证的起始超参数**，不是文献证明的最佳比例。当批次没有对应任务的已知标签时不计算该项。核心与 PTB-XL 交替批次可以从 3:1 起步，并确保整体患者/记录采样不由少数多 ECG 患者主导。不能把 MIMIC 大量批次简单淹没核心 OMI 训练。

先用自然患病率与未加权 BCE。若比较 class weight、正例过采样或 focal loss，单独报告：这些做法会改变分数分布，必须在原始比例的独立校准集重新校准。默认不加 PCGrad、动态 uncertainty weighting、对抗域适应和复杂课程学习；出现可复现的梯度冲突或域捷径后才做定向实验。

OMI/AMI/ACS 的层级约束需先核验原始标签关系，不能凭名称就强制 `P(OMI)≤P(AMI)≤P(ACS)`。简单独立 sigmoid 头是安全起点；CAD 不参与此层级。

### 5.3 8 GB 起始配置

AMP，实际 batch 从 8 开始，视峰值显存升至 16；梯度累积至有效 batch 32–64；AdamW；早停与学习率按开发集选择。预训练模型先冻结骨干可以显著降低反向传播资源，但大骨干前向缓存与输入 token 仍可能限制显存。所有资源数值需以实际试跑核实，不承诺某个公开基础模型能完整微调。

3 个随机种子首先用于稳定性评估。只有开发集证实集成改善判别和 NLL/Brier，才把三个模型顺序推理的集成放入最终方案，并在校准前完成组合；集成方差不直接叫作每位患者的真实概率置信区间。

## 6. 概率模块是架构的一部分

每个临床头先输出 logit `z`，冻结网络后用独立校准集拟合 `p = sigmoid(a*z+b)`。相较只有一个温度参数，带截距的二参数校准能调整总体风险偏移；是否采用固定温度版本由预先规定的方案决定。校准集阳性少时避免高自由度 isotonic。

单独报告 OMI、AMI 的 AUROC、AUPRC、NLL、Brier、校准截距/斜率及患者聚类区间。校准 ECE 很低可能只是预测集中在低患病率附近，不代表模型有用。用常数患病率模型做概率误差比较。

质量拒判和 OOD 检测不是校准的替代。深度集成的分歧、embedding 距离或能量分数可以做后续探索，但新域的过度自信仍可能发生，不能承诺检出所有不适用 ECG。

内部造影队列校准后的 OMI 概率只对应相近队列，不自动变成普通胸痛门诊概率。未来本地人群即使只取得少量标签，也要先明确校准和评估角色，不能在同一小批样本上反复校准后宣布外部验证成功。

## 7. 最小消融矩阵

| 实验 | 改变 | 所回答的问题 |
|---|---|---|
| A0 | 普通小型 12 通道 ResNet/CNN；单任务 OMI | 是否已能从原始波形学习超过现有统计特征模型的信息 |
| A1 | 共享逐导联 CNN + 有序线性导联合并 + mean/max pooling | 保留导联结构是否有收益，避免把注意力贡献和 stem 贡献混在一起 |
| A2 | A1 + 一层导联注意力 | 显式非线性导联关系是否有增益 |
| A3 | A2 + 两层时间 Transformer | 整段上下文是否有额外增益 |
| A3-TCN | 用轻量膨胀 TCN 替换两层时间 Transformer | 时间注意力是否值得额外复杂度；不与 Mamba/Transformer 同时叠加 |
| A4 | 所选结构 + AMI 辅助头 | 多任务是否改善或损伤 OMI |
| A5 | 同结构 PTB-XL 预训练/回放 | ECG 表型监督能否迁移到 OMI |
| F0/F1 | 原生公开基础编码器 + 冻结头 / 有限微调 | 预训练迁移是否比自定义模块更值得 |
| A6，可选 | 所选自定义结构 + MIMIC 自监督预训练 | 未标注本地规模是否产生标签效率收益 |
| A7，可选 | 已核验物理测量旁路 | 是否改善绝对幅值学习与误差可解释性 |

这是分阶段筛选，不要求对所有组合做笛卡尔积搜索。初筛后对候选重复 3 种子，最后锁定模型、校准器与阈值。研究目标优先检查 OMI AUPRC 和临床工作点的稳定变化，同时约束概率误差；不以单次 AUROC 上升 0.002 就保留一个新模块。不要在每轮消融重复查看最终测试集。

## 8. 超声扩展接口

目前不创建跨模态 Transformer。保留 ECG 固定 embedding（例如池化后的384维）和 logit 的可导出接口即可。

将来如果只有少量同患者、同临床时段的 ECG+超声：先从验证过的超声报告提取 EF、室壁运动异常等低维特征，或冻结可信的视频编码器；在有配对且有共同终点的训练患者中使用正则化后期融合。第一选择可以是 ECG logit + 少量超声特征的 logistic 模型，通常比把高维 ECG/video embedding 全部交给大网络更适合少量事件。

只有有超声病例可用于联合头的训练和评价；ECG-only 头继续单独服务无超声记录。不要用 missing-echo 位隐式代替风险信息而不审查检查选择偏倚。比较 ECG-only/echo-only/联合时必须使用同一配对患者子集、同一划分；无配对公共数据不能随机配对学习关联。视频帧/片段数量不能当作患者数量。

## 9. 必须避免的“缝合”错误

1. 修改预训练骨干的 stem、采样率、lead顺序或输入归一化，却声称完全复用了原始 checkpoint 的医学能力。
2. 同时堆 CNN、Transformer、Mamba、GNN、BiLSTM，但没有解释独立信息来源和单独消融。
3. 用每记录 z-score 消掉幅值后再让规则模块测 ST 毫伏；或噪声质量门控直接缩放波形。
4. 将 PTB-XL MI、临床 AMI、GU 缺血标签和 MIMIC 机器报告放入同一个同名头。
5. 预训练/微调后保留旧表型头，却不检查共享编码器变化引起的遗忘。
6. MIMIC 波形或 PTB-XL NORM 直接作为 CAD/OMI 阴性。
7. 从注意力图直接给出某条冠脉闭塞概率，或给没有临床标签的疾病输出病因概率。
8. 一个已知数据源才有一个临床标签，混合时模型靠设备特征识别来源；mask解决标签错误，不自动解决域捷径。
9. 从 OMI+CTO 或多个“缺血表现”分数拼出 CAD 总概率。
10. 依据内部高 AUROC 宣称面向未选择的胸痛人群可用，而不处理造影选择偏倚、时间差和概率迁移。

## 10. 原始方法依据和核验范围

以下来源在本次直接读取了原始网站页面；它们支持模块选择的基础，但没有证明上述自定义组合在本项目是最优模型。最新 ECG foundation models 的选择由并行调研报告承担。

- Ribeiro et al., **Automatic diagnosis of the 12-lead ECG using a deep neural network**, Nature Communications 2020. [原文](https://www.nature.com/articles/s41467-020-15432-4)。大规模12导联 DNN 的直接证据，疾病识别任务和数据并不等同于本项目 OMI。
- Fawaz et al., **InceptionTime: Finding AlexNet for Time Series Classification**, Data Mining and Knowledge Discovery 2020. [原始预印本与期刊 DOI](https://arxiv.org/abs/1909.04939)。多尺度一维卷积及残差的通用时序分类依据；不能拿其 UCR 等表现当作缺血模型临床证据。
- Guo et al., **On Calibration of Modern Neural Networks**, ICML 2017. [PMLR 原文页](https://proceedings.mlr.press/v70/guo17a.html)。支持神经网络分数需要独立校准；原文主要实验是图像/文本，不保证医疗迁移下校准有效。
